## 6.1. Раунди (RoundManager.js)

Фази: `waiting → buy (12с) → live (120с) → ended (6с) → buy → ...`

- **buy**: можна купувати (B), всі живі, боти респавняться.
- **live**: бій; кінець коли всі CT або всі T мертві; час вийшов → виграє CT.
- **ended**: пауза, показ ROUND WON/LOST, економіка нараховується.
- Після 30 раундів (15+15 зі зміною команд на 15-му) — **matchover**, екран з результатом + Rematch.

**Захист:** якщо на старті live одна команда порожня — повернення у buy (не застрягає).

**Ключові методи:**
- `startBuy(incrementRound)` — респавн гравця і ботів, спавн ботів якщо порожні.
- `startLive()` — перевірка живих команд перед стартом.
- `endRound(winnerTeam)` — рахунок, економіка, ROUND WON/LOST, matchover.
- `checkEndCondition()` — тільки на хості.
- `countAlive()` — живі CT/T (гравці + hostBots).
- `swapTeams()` — зміна команд на 15-му раунді (гравці + боти).
- `restartMatch()` — повний рестарт (рахунок, економіка, респавн).

## 6.2. Економіка (EconomyManager.js)

- Старт: $800. Максимум $16000.
- Вбивство: +$300.
- Перемога раунду: +$3250. Поразка: $1400 + $500 за кожну поразку поспіль (до 5).
- Ціни: AK $2500, M4 $3100, Deagle $700, броня $650, HE $300, Flash $200, Smoke $300.

**Синхронізація:** економіка рахується локально, але детерміновано:
- `roundEnd(won)` — через `round:state` (winner від хоста);
- `rewardKill` — через `game:kill` (killer отримує).

## 6.3. Двері (DoorSystem.js)

- **Авто-відкриття**: будь-який актор (гравець, бот, собака) ближче 1.6м — двері відчиняються.
- **E** — ручне відкриття/закриття.
- **Пошкодження**: стрільба ламає двері (doorWood).
- **Синхронізація**: стан дверей розсилається мережею.
- Стани: `closed / open / destroyed` (+ анімації).

## 6.4. Звук (AudioManager.js)

**Повністю процедурний** (Web Audio API, без файлів):
- постріли (за зброєю), влучання, вибухи, гранати;
- кроки (по матеріалу), стрибок, приземлення;
- hitmarker, dry fire, перезарядка;
- покупка, старт/кінець раунду;
- **radio-біпи ботів** (різні тони: spot/kill/cover/hurt);
- **ambient**: вітер + рідкісний пташиний спів (`updateAmbient(dt)` — викликається щокадру);
- **гавкіт собак** (через `sfx:bark` CustomEvent);
- позиційний звук (PannerNode) + HRTF.

**Ключове:** `startAmbient()` запускається при `unlock()`. `playRadio(position, kind)` — синтезований двотональний сигнал.

## 6.5. UI (ui/)

| Компонент | Клавіша | Опис |
|-----------|---------|------|
| HUD | — | приціл (розходиться з spread), HP, броня, гроші, патрони, гранати, радар, таймер раунду, індикатор шкоди (стрілка), ROUND WON/LOST |
| BuyMenu | B | купівля зброї/броні/гранат (цифри 1-7) |

| ChatUI | Y / U | чат усім / команді; Enter — відправити |
| NamePlates | — | імена + HP над гравцями/ботами (червоний — ворог) |
| KillFeed | — | стрічка вбивств справа вгорі |
| MatchOverScreen | — | кінець матчу + Rematch |
| LobbyUI | — | лобі: ім'я, карта, гравці, START |

**Інше:**
- F1 — debug overlay (боти/двері/позиції/FPS).
- ⛶ (верхній правий кут) — повний екран.
- **Pointer Lock**: ESC виходить з lock; меню закрилось → `relockPointer()` повертає мишу; fullscreen change → relock через 100-150мс; при відхиленні браузера — `_armRelockOnNextGesture()` (наступний клік/клавіша).

## 6.6. NamePlates (ui/NamePlates.js)

- 2D overlay (HTML) поверх canvas.
- Показує ім'я + HP над гравцями/ботами; червоний = ворог, білий = союзник.
- Оновлюється через `updateNamePlates()` у main.js (проекція 3D → екран).
- Ховає за екраном (vector.z > 1 || < -1).
