## 8.1. Що вже налаштовано (не чіпати)

| Файл | Що робить |
|------|-----------|
| `vite.config.js` | `base: './'` — відносні шляхи, критично для Pages |
| `.github/workflows/deploy.yml` | CI: build + `actions/deploy-pages` на кожен push у main |
| `public/.nojekyll` | Забороняє Jekyll ламати шляхи на Pages |
| `scripts/build.mjs` | Підміняє index.html (збірка ↔ dev) перед build |
| `scripts/dev.mjs` | Те саме для dev-режиму |

## 8.2. index.html — особливість проекту (ВАЖЛИВО)

- **`index.html` у корені = ЗБІРКА** (посилається на `assets/index-*.js`) — потрібен для Pages (обслуговує корінь main).
- **`index.src.html` = вихідний dev-файл** (посилається на `/src/main.js`) — потрібен Vite.
- Скрипти `npm run dev` і `npm run build` **самі підміняють** index.html:
  - dev: index.html → index.src.html (Vite працює), після зупинки → назад;
  - build: те саме, після збірки повертає збірний index.html.
- **`assets/` у корені = збірка для Pages** — оновлюється з dist/assets при деплої.
- **НЕ редагуй index.html/index.src.html/assets вручну** — вони генеруються.

## 8.4. Нюанси та пастки

1. **Без `base: './'`** гра не знайде ассети на Pages — НЕ змінюй.
2. **WASM-модуль Rapier** вантажиться асинхронно — на Pages працює, перше відкриття може бути повільніше.
3. **Скріншоти/тимчасові файли** (*.png, .playwright-mcp/) — в `.gitignore`, не комітяться.
4. **Firebase секрети**: `config.js` публікується. Для RTDB це ок (правила БД захищають), але **ніколи** не клади приватні ключі сервіс-акаунта.
5. **Мультиплеєр на Pages**: LocalAdapter — тільки вкладки одного браузера. Для різних ПК — Firebase (розділ 8.5).
6. **Кеш**: після оновлення гравці можуть бачити стару версію — хард-рефреш (Ctrl+F5).
7. **GitHub Actions квота**: build ~1 хв на push — вистачає.

## 8.5. Мультиплеєр між різними ПК (опційно, ~15 хв)

1. Створи Firebase проєкт → Realtime Database (`us-central1`).
2. Правила БД (Firebase Console → Rules):
```json
{
  "rules": {
    ".read": true,
    ".write": true
  }
}
```
3. Заповнити `src/config.js` даними проєкту (apiKey, authDomain, databaseURL, projectId, appId).
4. `git commit -m "firebase multiplayer"` → `git push` → CI задеплоїть.
5. FirebaseAdapter підхоплюється сам (якщо є `apiKey` + `databaseURL`).

## 8.7. FAQ (поширені питання при правках)

**Q: Гра не стартує — порт зайнятий?**
Vite сам обере вільний порт (5174, 5175...). Дивись адресу у виводі терміналу.

**Q: Змінив код, але нічого не змінилось?**
Dev-сервер має HMR — збережи файл і онови сторінку (F5). Якщо правка в WASM-фізиці — повний рестарт dev.

**Q: Ботів замало / забагато?**
`TEAM_SIZE` у `NetworkBots.spawnHostBots()` — кількість слотів на команду (зараз 5).

**Q: Де змінити, скільки життя забирає зброя?**
`weapons/defs/*.js` → поле `damage`. Зони: head ×4 (headshotMultiplier), stomach ×1.25, legs ×0.75 (zoneMultipliers).

**Q: Боти не вмирають від пострілу — чому?**
1. Ти стріляєш у ворога? (friendly fire виключено — куля проходить крізь союзників);
2. Куля пробила стіну і втратила шкоду? (пробивання знижує damage);
3. Бот живий? (мертві боти не мають hitbox);
4. Це старий бандл? (хард-рефреш Ctrl+F5).

**Q: Боти не бачать гравця?**
Перевір що `rayFilter()` не видалений (docs/02-networking.md, розділ 2.8). Це виключає власні hitbox-зони з raycast.

**Q: Миша не працює після ESC/повного екрану?**
Виправлено: `relockPointer()` при закритті меню, `fullscreenchange` → relock, `_armRelockOnNextGesture()` при відхиленні браузера. Якщо знову — перевір `InputManager.js` методи.

**Q: Мультиплеєр між комп'ютерами не працює?**
LocalAdapter працює тільки в межах одного браузера (вкладки). Для інтернету — Firebase (розділ 8.5).

**Q: Що означає помилка `[InputManager] Pointer Lock error`?**
Це не помилка — браузер відхилив запит Pointer Lock (не було user gesture). Клікни в гру.

**Q: Як перевірити чи боти воюють між собою?**
Скорборд (Tab) під час live — K/D ботів ростуть. Або F1 → debug overlay.

**Q: Гра повільна (FPS < 30)?**
F1-оверлей. Знизь pixelRatio (main.js initRenderer — зараз 1.75) або вимкни тіні (shadowMap).

**Q: Build падає з "Cannot reassign const"?**
Причина: кореневий index.html був збіркою, Vite намагався його трансформувати. Рішення: `npm run build` тепер йде через `scripts/build.mjs` (підміна index.html). Не викликай `vite build` напряму.

## 8.9. Відомі обмеження / нотатки

1. **FirebaseAdapter** потребує заповнити `config.js`. Порожній → локальний режим.
2. **PeerJSAdapter** — P2P, потребує додаткового налаштування (не основний шлях).
3. `BotManager.js`/`Bot.js` — мертвий код (замінений NetworkBots), не видалявся.
4. Гранатний fuse може десинхронізуватись ~100мс між клієнтами (косметично; шкода рахує хост).
5. Зброя не скидається при смерті (свідомо — зберігається між раундами).
6. Економіка частково локальна (spend не перевіряється хостом) — для кежуал-гри ок.
